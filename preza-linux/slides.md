# Введение в Linux

---

# Что такое Linux
Семейство Unix-подобных ОС

- Ядро с открытым исходным кодом (github.com/torvalds/linux)
- Сообщество разработчиков, Линус Торвальдс -- в корне
- Строится вокруг идеи свободного ПО

<div grid="~ cols-2 gap-5" m-t="2">
<div>

### Плюсы открытости

- Всё, что можно придумать, кто-то уже сделал
- Популярное ПО очень стабильно
- Пользователи видят код и правят баги

</div>
<div>

### Минусы открытости

- Непопулярное ПО может быть плохим
- Часто пишется новичками без опыта
- Нет единых стандартов на архитектуру

</div>
</div>

---

# Где применяется Linux

- **Серверная ОС** -- лидер с огромным отрывом
- **Встроенные устройства** -- открытость, модульность
- **Профессиональная разработка** -- зрелый инструментарий
- **Enterprise, веб, облака** -- близость к production-окружению


<br> 

### Почему не весь мир на Linux?

- Проприетарное ПО (Adobe, Office) -- часто нет версий под Linux
- Игры: DirectX/античиты, не всё запускается
- Отдельные проприетарные драйверы (NVIDIA, Wi-Fi Broadcom)

# Что такое дистрибутив
Готовая к использованию система

Ядро само по себе не имеет пользовательского интерфейса.

Дистрибутив = ядро + шелл + утилиты + графическая оболочка + пакетный менеджер + конфигурация + политика обновлений

# Популярные дистрибутивы

- **Ubuntu** -- десктопный "по умолчанию", обновления раз в полгода
- **Fedora** -- от Red Hat/IBM, осторожна с патентами, без проприетарного кода в основной поставке
- **Debian** -- старейший (1993), база для Ubuntu/Mint
- **Arch** -- частые обновления, для опытных; на его базе SteamOS

- **Mint** -- на базе Ubuntu, свой рабочий стол
- **Gentoo** -- всё из исходников (для фанатов)
- **Альт, РОСА, Астра, РЕД ОС** -- российские, платные/бесплатные
- Сотни дистрибутивов в целом

# Линукс для программистов

<br>

- **Бесплатна** -- ВМ и контейнеры в любом количестве, без лицензий
  - Нюанс: есть рынок небесплатных дистрибутивов (свобода ПО ≠ нельзя заработать)
- **Конфигурируема** -- от полного десктопа до систем в десятки мегабайт
- **Удобная консоль** -- вылизана, мощная, shells как язык программирования
- **Пакетный менеджер** -- одна команда на установку

<br>

Стандартный инструментарий разработчика (компилятор, отладчик, утилиты) ставится одной командой

# Отличия от Windows

- Регистр имеет значение: `a.txt` ≠ `A.txt`
- Нет дисков -- один корень `/`
- Монтирование внешних ФС в поддиректории
- Слеши прямые `/`, не обратные
- Нет реестра -- всё текстовые файлы, человекочитаемые конфигурации
- Оконный менеджер -- обычное внешнее приложение
- Пакетный менеджер
- Другая идеология (независимая от Windows): **Unix way** -- много маленьких программ + связывание их в цепочки пайпами (см. слайд про перенаправление)

# Среды рабочего стола
Что видит пользователь

<br>

Графический сервер: **X Server** (старый) или **Wayland** (новый)

<br>

# Пользователи и root
Кто имеет права

<br>

**root** -- суперпользователь, может ВСЁ (удалить систему, сломать права, поставить пакеты)

<br>

```bash
whoami              # текущий пользователь
id                  # UID, GID, группы
sudo <команда>      # выполнить от имени root
```

<br>

Не логиниться как root по умолчанию: одна ошибка = повреждение системы

`sudo` -- временно получить права root для одной команды (запросит пароль)

# Wildcards (глобы)
Шаблоны имён файлов

- `*` -- Любое количество любых символов
- `?` -- Ровно один любой символ
- `[1-8]` -- Одна цифра от 1 до 8
- `[!a-z]` -- Не строчная буква

<br>

```bash
rm -rf *.txt        # удалить все .txt

```

Раскрываются **до** вызова команды

# Настройка системы
Настройка = правка текстового файла

<br>

```bash
echo $PS1        # текущий приглашение шелла
nano ~/.bashrc   # можно открыть в текстовом редакторе и поменять
source ~/.bashrc # применить
```

<br>

Ключевая идея: никакого реестра -- всё лежит в `/etc/` (глобально) или `~/` (пользователь), редактируется через текстовый редактор

# Права доступа

<br>

Три группы (владелец, группа, остальные) по три бита: **r**ead, **w**rite, e**x**ecute

```bash
chmod +x file.txt    # сделать файл исполняемым
ls -l                # показать права (rw-r--r--)
```

Без атрибута Execute файл **нельзя запустить** -- даже скрипт или бинарник

Права директорий: можно иметь право писать файлы (зная имя), но не читать список файлов

# FHS: Filesystem Hierarchy Standard

<br>

- Файлы бывают **изменяемые/статичные** × **разделяемые/неразделяемые**
  - Разные условия доступа по сети и бэкапов → должны лежать в разных директориях
- Корневая ФС (`/`) -- только самое необходимое для загрузки и восстановления
  - Остальное подмонтируется: на других дисках, разделах или в сети
  - Никто не мешает им быть на одном разделе с корневой
- `/usr` -- основная иерархия программ; в современных системах (merged `/usr`) тут живёт всё, включая системную инициализацию
- Запрещено создавать файлы и директории в корне

# systemd: сервисы
Программы, которые работают в фоне

- **Сервис** -- программа, запускаемая самой системой и работающая в фоне: Bluetooth, сеть, принтер
- **`systemd`** -- система инициализации, запускает и контролирует все сервисы
- **`systemctl`** -- команда для управления сервисами через `systemd`

```bash
systemctl status bluetooth     # работает ли Bluetooth?
systemctl start bluetooth      # запустить
systemctl stop bluetooth       # остановить
systemctl restart bluetooth    # перезапустить
systemctl enable bluetooth     # автозапуск при загрузке
```

```bash
journalctl -u bluetooth                # логи сервиса
journalctl -u bluetooth --since today  # логи за сегодня
```

<br>

Сервисы: `bluetooth` (Bluetooth), `NetworkManager` (сеть), `cron` (расписание задач), `sshd` (удалённый SSH), ...

# Vim

Полноценный интерактивный редактор в консоли

<br>

Для простых правок проще начать с **nano**: есть на любом сервере, подсказки внизу экрана, `Ctrl-O` -- сохранить, `Ctrl-X` -- выйти

Когда нужна мощь -- **Vim**:

### Базовые команды

- `i` -- режим ввода
- `Esc` -- выход из режима ввода
- `:wq` -- сохранить и выйти
- `:q!` -- выйти без сохранения

<br>

- Есть плагины, можно как IDE
- Обязательно освоить хотя бы одно из двух

# Ещё полезное в консоли

<br>

- **Tab** -- автодополнение (в контексте). Дважды -- список вариантов
- **`~`** -- домашняя директория (`cat ~/.bashrc`)
- **`alias`** -- синонимы команд (`alias gcc="gcc -Wall"`)
- **Midnight Commander** -- консольный файловый менеджер
- **Ctrl-R** -- поиск по истории команд
- **Ctrl-W** удалить слово, **Ctrl-U** до начала, **Ctrl-K** до конца
- **Ctrl-A / Ctrl-E** -- начало/конец строки
- **Выделение мышкой + средний клик** -- вставка (не через буфер!)
- **Ctrl-Alt-F1..F6** -- переключение на текстовые терминалы
